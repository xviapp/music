# 更新记录

### 2026-10-09

#### 优化

- 音乐应用图标统一为奶油底、灰青绿猫和暖橙耳机的扁平剪纸风格，猫脚和耳机套使用清晰对比色。

### 2026-10-08

#### 优化

- 桌面图标统一为简洁的哑光黏土风，保留蓝灰色猫背影、琥珀色耳机和圆形裁切适配。

### 2026-10-07

#### 优化

- 桌面图标更换为戴琥珀色耳机的蓝灰色猫背影，并适配圆形等桌面图标裁切。
- 首页入口和歌单布局更紧凑，推荐内容更早可见；搜索、音乐库及歌单详情会保留浏览位置和已有内容。
- 播放器补充循环、随机、定时和歌词跟随状态反馈，歌词支持手动浏览后回到当前句。
- 私人 FM 直接进入当前歌曲的播放页，隐藏首批推荐列表，并在播放队列接近耗尽时继续取歌。

#### 修复

- 冷启动先应用已保存的主题，再显示首页，避免首页从默认浅色跳变到深色；启动背景同步适配深色模式。
- 播放器在总时长暂不可用时不再把进度条误显示到末尾，并会回退使用歌曲元数据时长。
- 刷新、分页和网络失败时保留已显示内容，补充封面失败、空列表和错误重试反馈。

### 2026-10-06

#### 新增

- 歌曲详情和播放页支持进入歌手主页，查看热门歌曲、全部歌曲、专辑及简介。
- 支持收藏／取消收藏歌手与专辑，并在音乐库查看收藏列表。
- 首页新增排行榜入口，支持浏览榜单歌曲。
- 歌曲详情和播放页新增评论入口，可查看热门评论、最新评论及回复，支持分页。
- 搜索提供关键词建议，选择建议后即可搜索。

#### 优化

- 搜索建议适配中文输入法，快速输入或切换页面时避免显示过期建议。
- 正式安装包使用固定签名，便于后续覆盖升级。

### 2026-10-05

#### 新增

- 歌曲详情支持查看歌曲信息、加入播放队列及喜欢／取消喜欢。

#### 优化

- 点击歌曲封面、标题和最近播放条目先查看详情，点击播放按钮才开始播放；私人 FM 可先浏览歌曲。
- 播放页展开、收起和歌词滚动更流畅，并适配减少动态效果设置。

#### 修复

- 修复点击“打开官方登录”时应用闪退的问题。
