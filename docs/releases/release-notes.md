# 更新记录

### 2026-10-17

#### 新增

- 项目采用 MIT 协议，补充隐私说明、免责声明、安全反馈、贡献和发布指引。

#### 修复

- “关于”页面显示当前安装版本，避免升级后仍显示旧版本号。

### 2026-10-12

#### 新增

- 歌曲详情支持“下一首播放”；播放队列支持拖动排序和一键清空。
- 私人 FM 提供“不喜欢”，减少类似推荐并切到下一首；通知栏和系统媒体控件新增“喜欢”，FM 模式下另有“不喜欢”。
- 搜索页在输入前显示搜索历史和热门搜索；搜索历史保存在本机，可清除，退出登录时一并清除。
- 歌词显示翻译；迷你播放条显示播放进度；定时关闭新增 45、90 分钟并显示剩余时间。
- 设置新增“点击歌曲直接播放”，默认关闭，仍先打开歌曲详情。
- 听过的音频在本机缓存，最多 512 MB，重复播放时少用流量。

#### 优化

- 歌单和喜欢的音乐“播放全部”会把整张歌单排入队列（最多 1000 首），未加载的歌曲在后台补齐。
- 遇到无版权或仅可试听的歌曲时自动跳到下一首并提示，连续 3 首失败后停止跳过；私人 FM 会先补充歌曲再跳过。
- 切换音质后立即按新音质重新加载当前歌曲，同一首歌的分段请求不再混用两种音质。
- 播放进度与播放队列分开同步，暂停时不再频繁传输和保存整个队列。
- 歌单刷新时保留返回路径；部分歌曲不可用时，“加载更多”不再重复请求同一批歌曲。

#### 修复

- 退出登录后会清除官方登录网页的 Cookie；每次打开官方登录都从全新会话开始，不会自动登回旧账号或沿用已过期的登录。
- 官方登录页禁止加载混合内容。

### 2026-10-09

#### 优化

- 音乐应用图标统一为奶油底、灰青绿猫和暖橙耳机的扁平剪纸风格，猫脚和耳机套使用清晰对比色。

### 2026-10-08

#### 优化

- 桌面图标统一为简洁的哑光黏土风，保留蓝灰色猫背影、琥珀色耳机和圆形裁切适配。

### 2026-10-07

#### 优化

- 桌面图标更换为戴琥珀色耳机的蓝灰色猫背影，并适配圆形等桌面图标裁切。
- 首页入口和歌单布局更紧凑，推荐内容更早可见；搜索、音乐库及歌单详情会保留浏览位置和已有内容。
- 播放器补充循环、随机、定时和歌词跟随状态反馈，歌词支持手动浏览后回到当前句。
- 私人 FM 直接进入当前歌曲的播放页，隐藏首批推荐列表，并在播放队列接近耗尽时继续取歌。

#### 修复

- 冷启动先应用已保存的主题，再显示首页，避免首页从默认浅色跳变到深色；启动背景同步适配深色模式。
- 播放器在总时长暂不可用时不再把进度条误显示到末尾，并会回退使用歌曲元数据时长。
- 刷新、分页和网络失败时保留已显示内容，补充封面失败、空列表和错误重试反馈。

### 2026-10-06

#### 新增

- 歌曲详情和播放页支持进入歌手主页，查看热门歌曲、全部歌曲、专辑及简介。
- 支持收藏／取消收藏歌手与专辑，并在音乐库查看收藏列表。
- 首页新增排行榜入口，支持浏览榜单歌曲。
- 歌曲详情和播放页新增评论入口，可查看热门评论、最新评论及回复，支持分页。
- 搜索提供关键词建议，选择建议后即可搜索。

#### 优化

- 搜索建议适配中文输入法，快速输入或切换页面时避免显示过期建议。
- 正式安装包使用固定签名，便于后续覆盖升级。

### 2026-10-05

#### 新增

- 歌曲详情支持查看歌曲信息、加入播放队列及喜欢／取消喜欢。

#### 优化

- 点击歌曲封面、标题和最近播放条目先查看详情，点击播放按钮才开始播放；私人 FM 可先浏览歌曲。
- 播放页展开、收起和歌词滚动更流畅，并适配减少动态效果设置。

#### 修复

- 修复点击“打开官方登录”时应用闪退的问题。
